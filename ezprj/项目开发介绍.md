# 快速了解我们

我们是一支由大厂工程师及高校竞赛获奖成员组成的工程开发团队，不同于传统模板化毕设方案，我们能够支持从基础功能实现到复杂系统开发的不同类型项目。

团队具备完整的软硬件研发能力，覆盖：

- 嵌入式控制系统开发：STM32、ESP32等单片机应用开发，包含传感器采集、电机控制、通信协议、上位机交互等；
- FPGA开发设计：图像处理、数字信号处理、硬件逻辑设计、接口控制等相关项目开发；
- 机械结构设计与外观设计：结构建模、零件设计、复杂装配体设计，传动系统设计，实物加工等；

团队成员拥有丰富竞赛及工程项目经验，熟悉高校毕业设计评价标准，能够根据不同专业老师关注重点，对项目方案、技术路线和展示形式进行优化。普通项目我们能高效交付，复杂项目别人做不了我们能做。

### 二、项目费用与服务内容

#### 1.  项目费用

常规项目的基础开发费用为 1600元/项，定金500元。

对于常规项目的定义是：项目不涉及复杂算法、复杂机械结构、定制化的PCB设计（如自行设计某个传感器模块电路）或其他工作量较大的内容。非常规项目将根据实际需求单独报价。

项目费用不包含器件成本，在满足已确认功能和稳定运行的前提下，我们会优先选择性价比较高的硬件方案。需要你按照实际采购金额承担器件成本，最高不超过300元，超过300元的部分由我们承担。器件成本可联系老师或学校报销。

常规项目总费用 = 基础开发费1600元（定金500 + 尾款1100）+ 器件成本（据实，最高300元封顶，可报销）。

**最终费用以双方在付款前确认的报价为准。未经你确认，不会产生额外费用。**

### 四、想调整或新增功能怎么办

对于需求调整，我们的原则是：

- 已确认功能未按约定标准实现，由我们免费修复；

- 小范围调整，通常免费；

- 少量小功能，通常免费；

- 影响整体方案或造成大量返工，需要重新确认；

- 明显超出原需求范围的较大功能，需要重新确认；

- 已交付项目新增或调整功能

我们支持合理调整。只有涉及整体方案变化、明显增加开发工作量的需求，才需要重新评估。相关问题的具体定义如下：

| 问题项目                 | 解释                                                         | 示例问题                                                     | 解决方案           |
| ------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------ |
| 已确认功能未按标准实现   | 如果已经确认的功能没有正常实现，属于原项目范围内的问题，我们会负责修改，不作为新增需求收费。 | 已确认需要显示温度，但无法正常显示；已确认按键控制，但按键无法操作；等 | 免费修复           |
| 小范围修改               | 开发过程中，如果你或指导老师提出少量调整，在不改变硬件方案、机械结构和整体技术方案，并且不会造成较大返工的情况下，我通常会直接协助修改，不额外收费。 | 调整参数、阈值和运行时间；修改文字、名称或显示内容；调整按键、指示灯或界面的简单逻辑；等 | 通常免费           |
| 少量小功能               | 如果新增功能**可以直接基于现有硬件和程序实现**，不需要增加新的开发平台、通信方式或主要硬件，也不会明显影响原定交付时间，不额外收费。 | 增加一个简单的数据显示；增加一个按键控制功能；增加一个状态提示；等 | 通常免费           |
| 新增大功能               | 如果新增功能会明显增加开发工作量，或者需要增加新的软件、平台、算法或通信模块，将作为较大功能单独评估 | 新增上位机软件；新增手机App或小程序；新增图像识别、语音识别、路径规划等复杂算法；其他明显超出原需求范围的功能；等 | 单独确认费用和时间 |
| 影响整体方案             | 如果项目已经完成大部分程序开发、硬件制作或功能调试，但你或指导老师提出更换主控、通信方式、机械结构或整体技术方案，原有成果可能无法直接继续使用 | 更换单片机、增加新PCB、改变外壳结构、完成大部分开发后更换方案 | 单独确认费用和时间 |
| 已交付项目新增或调整功能 | 项目正式交付代表原开发任务已经完成。交付后，除原功能问题修复外，对功能逻辑、参数、界面、硬件或机械结构进行调整，或者增加新的功能，均属于二次开发，不再自动适用开发过程中的免费小修改规则 | 交付后要求修改控制逻辑、增加数据显示、增加按键功能、更换传感器、增加通信功能或调整机械结构 | 单独确认费用和时间 |

> 往年经验以供参考：
>
> **示例一：项目交付后的新增功能**
> 同学A项目已经正式交付，原约定功能也已正常实现。他的指导老师要求增加上位机软件，且开发时间不紧迫。该功能属于交付后的二次开发。双方确认后，收取200元二次开发费；并承担实际往返快递费。
>
> **示例二：开发过程中的新增功能**
> 同学B项目仍处于开发过程中，指导老师提出增加上位机软件。由于此时可以与原项目同步开发，返工量相对较小，双方确认增加100元功能开发费，原交付时间不变。

### 六、关于售后

1. **首次运行保障**

项目寄出前，我们会完成组装、程序烧录和约定功能测试，并提供整体运行演示视频。项目首次签收时保障能够按照已确认的功能正常运行。若由于快递运输等原因你收到项目后无法运行的，我们全额免费售后支持，直到你能够正常运行项目。

2. **一次免人工费维修**

项目已经完成首次正常运行后30天内，如果因你接线错误、供电错误、操作不当、跌落碰撞或其他原因造成器件烧毁、线路损坏或机械结构损坏，我们提供一次免维修人工费服务。本次维修不收取维修人工费，你只需承担维修实际产生的器件费、材料费及往返快递费。

3. **后续再次损坏**

使用前述一次免人工费维修服务或首次正常运行超过30天后，如果再次因你的原因造成硬件或机械结构损坏，后续维修按照以下方式收费：维修费用＝实际器件及材料成本＋往返快递费＋100元/次维修人工费。

> 硬件或机械结构损坏往往是由于接线错误、供电电压或极性错误、带电插拔、跌落碰撞等操作造成。如果你不确定某一步是否可以操作，请先停止通电并留言确认。

4. **答疑**

基础开发费用包含售后期内针对具体操作问题和原功能问题的基础答疑，基础售后只处理具体、明确、可以定位的问题；系统性基础知识讲解、开放式咨询和一对一的学习辅导属于增值服务。售后问题可以随时留言，我们将在每天晚上 **21:00—24:00** 集中查看和回复。白天发送的问题请先留言，无需重复催促。我们会为你提供答疑服务直到你完成结题答辩。

> 白天我们也会对紧急情况及时进行相应

### 七、关于原创性与保密

我们理解项目对独立完成和原创性的要求，就此作出以下承诺：

1. **同届不重复交付**

你的项目由我们独立开发。在同一交付周期内（即你所在的毕业季），我们不会将你的完整方案（整体功能设计、程序工程与硬件资料）交付给其他同学，确保你不会与同届、同专业同学出现项目雷同。

2. **保密**

在你顺利毕业前，我们不会向任何第三方泄露你的项目需求与研发资料，也不会公开你的项目。此后我们可能会选取部分优秀项目用于宣传展示，但仅展示项目功能与技术成果，不含任何可能识别你个人身份的信息。

### 八、增值服务

项目交付后如果你认可我们的流程与项目成果，可以与我们沟通获取进一步的增值服务。
